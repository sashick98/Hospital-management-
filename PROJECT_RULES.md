# Hospital Management System - Project Guide & Rules

Welcome to your Hospital Management System full-stack learning project!

---

## 🎯 Project Objective
This project is dedicated to your hands-on journey in mastering **Backend Development** using Node.js & Express.js, while having a fully responsive, clean **React + Bootstrap** frontend to interact with.

---

## ⚖️ Division of Responsibilities

| Role | Assigned To | Scope |
| :--- | :--- | :--- |
| **Frontend** | **AI Assistant** | React (Vite), Bootstrap 5, Axios, modular components, responsive UI, API service layer |
| **Backend** | **You (Ashick)** | Express.js, server setup, REST APIs, routing, controllers, middleware, models, database (MongoDB/SQL), authentication, error handling |

## 📜 Strict Collaboration Rules
1. **Frontend Only for AI**: The AI will never touch, create, or alter any files inside `backend/`.
2. **No Backend Code from AI**: No `server.js`, `app.js`, Express routes, controllers, or database schemas will be generated by the AI.
3. **API Contract Mode**: Every time frontend code communicates with an API, the AI will provide a complete **API Contract** specifying:
   - **Endpoint** (e.g., `POST /api/patients`)
   - **HTTP Method** (`GET`, `POST`, `PUT`, `DELETE`)
   - **Request Payload** (JSON structure)
   - **Expected Success Response** (Status code + JSON)
   - **Expected Error Responses** (Status code + error messages)
   - **Frontend UI Behavior** (How the data is handled in React state)
4. **Learning-First Debugging**: If an API fails or returns an error, the AI will explain what the frontend sent and what it was expecting, empowering you to debug and write the backend fix yourself.

## 🚀 Getting Started

### 1. Running the Frontend
```bash
cd frontend
npm run dev
```
By default, the Vite dev server runs at: `http://localhost:5173`

### 2. Setting Up Your Backend
When you're ready, navigate to `backend/` and initialize your Node project:
```bash
cd backend
npm init -y
npm install express cors dotenv
```
*(Suggested default backend port: `5000` or `8000`)*
