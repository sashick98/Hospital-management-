# 🏥 CarePulse - Hospital Management System

A modern full-stack Hospital Management System built with **React 19**, **Bootstrap 5**, **Express.js**, and **MongoDB**. Designed with a clean, high-performance UI for clinical administration, patient admissions, and doctor appointment scheduling.

---

## 🌟 Key Features

- **📊 Comprehensive Clinical Dashboard**: Live metrics for bed capacity, patient flow, doctor availability, and department telemetry.
- **👨‍⚕️ Specialist & Doctor Management**: Profiles, ratings, departments, and consultation scheduling.
- **📋 Patient Admission & Directory**: Complete patient records, triage details, blood group registry, and contact info.
- **📅 Appointment Booking System**: Real-time appointment scheduling, status tracking (`Scheduled`, `Completed`, `Cancelled`), and notes.
- **🛡️ Built-in API Learning Hub**: Interactive API contracts and health-check indicators designed for Express & MongoDB integration.

---

## 🚀 Tech Stack

### Frontend
- **React 19** with **Vite**
- **Bootstrap 5** & **Bootstrap Icons**
- **Axios** for centralized API communication
- Custom modern design system

### Backend (Express & MongoDB)
- **Node.js** & **Express.js**
- **MongoDB** with **Mongoose ODM**
- **CORS** & **Dotenv** configuration

## 💻 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/sashick98/Hospital-management-.git
cd Hospital-management-
```

### 2. Run the Frontend
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Run the Backend (Optional for live data)
```bash
cd backend
npm install
npm run dev
```
Backend runs on [http://localhost:5000](http://localhost:5000).
